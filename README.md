# 🌊 ReefPal · 海水缸助手

> 一个面向海水缸爱好者的**全流程管理工具**：水质记录与智能分析、元素补充计算、滴定方案配置、换水管理、数据备份，支持桌面与手机（PWA）。

基于 **Python FastAPI + SQLite + 纯前端（无框架）**，本地运行、数据私有、可一键部署。

---

## ✨ 核心功能

### 📈 水质记录与智能分析
- 记录 KH / 钙 / 镁 / NO₃ / PO₄ 测试值（建议每周 1-2 次）
- **L1-L5 分层分析**：单点状态 → 趋势感知 → 异常检测(z-score) → 规则组合 → 趋势预测
- 简洁/深度双模式：仪表盘卡片 或 ECharts 趋势图（含理想范围色带、滴定/换水标记、滚轮缩放）
- **综合趋势**：多元素归一化为相对变化(%)，对比不同尺度元素走势
- **智能建议带具体行动**：偏低时自动算出"需补 X ppm → 目标 Y"，一键跳转元素补充页算用量
- **元素联动诊断**：镁钙析出、营养失衡、沉淀风险等跨元素因果分析

### 🧪 元素补充计算
- 5 组 19 元素试算表（核心/进阶/微量/营养/治疗用药），按主流参考值校验
- 输入实测值自动判断缺口并算用量；多添加物可选（如钙可选氯化钙/氢氧化钙）
- 与滴定方案联动：一键把实测值带入滴定页算每天滴定量

### 💧 滴定方案
- 配液浓度计算（分析纯 + RO水）+ 常用配比参考（稀/浓一键填入）
- **消耗测算**：两次实测推算每日消耗
- **目标调节**：输入目标值与计划天数，算出每天滴定量（含每日消耗补偿）
- ⚠️ **每日提升超限提醒**：KH>0.5dKH/天、钙>25ppm/天、镁>50ppm/天 → 红色紧急提示并建议安全天数
- 开始/结束滴定自动记录，趋势图上以色带/标记呈现

### 🧂 换水管理
- 记录换水（水量/盐品牌/备注），趋势图标记换水日
- 海盐品牌元素配比参考（19 品牌，数据整理自公开用户分享）
- 配盐计算：按品牌盐重自动算需要多少克

### 🛡️ 数据与体验
- **数据备份**：JSON 完整导出/导入（自动去重）、CSV 单表导出（Excel 可打开）
- **新手引导**：首次使用 3 步上手，随时可从「入门指南」找回
- **PWA 支持**：手机浏览器"添加到主屏幕"即像 App
- **移动端优化**：滑动切 tab、触感反馈、数字键盘、安全区适配、触摸目标 ≥40px
- **"稳字当头"**：全流程贯彻"海缸养的是稳定，切忌大升大降"的养缸理念

## 🚀 快速开始

### 本地运行
```bash
cd seawater-app
pip install fastapi uvicorn
python main.py
# 浏览器打开 http://127.0.0.1:8000
```

### Windows 一键启动（支持手机访问）
```bash
start.bat
# 手机连同一 WiFi，浏览器打开 http://你的IP:8000（start.bat 会提示查 IP）
```

### 手机 PWA 体验
1. 手机与电脑连**同一 WiFi**
2. 浏览器访问 http://电脑IP:8000
3. 浏览器菜单 → **添加到主屏幕** → 像 App 一样使用

```
└── requirements.txt         # fastapi + uvicorn
```

## 🗂️ 数据存储

数据保存在本地 SQLite（water_records.db，已 gitignore 不入库）：
- water_records：水质测试记录
- dosing_log：滴定记录（开始/结束/调整）
- water_change：换水记录

建议定期用「💾 数据备份」导出 JSON 留存。

## 🧠 数值参考（主流共识）

| 参数 | 理想范围 | 备注 |
|---|---|---|
| 水温 | 25-27°C | 珊瑚稳定生长 |
| 盐度 | 35ppt / 1.025 | |
| KH 碱度 | 8-12 dKH | SPS 建议 8-9 |
| 钙 | 400-450 ppm | SPS 建议 420-450 |
| 镁 | 1300-1400 ppm | SPS 建议 1350-1400 |
| NO₃ | 2-10 ppm | 过低珊瑚生长停滞 |
| PO₄ | 0.03-0.08 ppm | 过低珊瑚褪色 |
| NO₃:PO₄ | ≈100:1 | Redfield 比例 |
