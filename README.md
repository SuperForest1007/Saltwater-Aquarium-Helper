# 🌊 ReefPal · 海水缸助手

> 一个面向海水缸爱好者的**全流程管理工具**：水质记录与智能分析、元素补充计算、滴定方案配置、换水管理、数据备份，支持桌面与手机（PWA）。

基于 **Python FastAPI + SQLite + 纯前端（无框架）**。数据保存在运行服务的主机上；同一服务地址的设备会访问同一份数据。

---

## ✨ 核心功能

### 🐠 我的鱼缸
- 首次只需设置**实际水量、主要类型、当前阶段**，之后显示为可随时编辑的鱼缸铭牌
- 支持 **FOT / 软体 / LPS / SPS / NPS / 混养** 六类起始参考方案
- 设置时直接解释六类区别并预览五项参考范围；不知道实际水量时可按缸体尺寸、水位、造景和底缸估算
- 缸型差异同时展示“平时更该盯什么”，不靠刻意拉大基础海水参数来制造区别；“软体 / 海葵”会明确说明两者并非同一生物分类
- 水质分析、元素联动、补充计算、滴定和维护记录共用同一份鱼缸上下文
- 数据库已预留 `tank_id`，当前保持单缸低负担体验，未来扩展多缸无需重做历史记录

### 📈 水质记录与智能分析
- 记录 KH / 钙 / 镁 / NO₃ / PO₄ 测试值（建议每周 1-2 次）
- **L1-L5 分层分析**：单点状态 → 趋势感知 → 异常检测(z-score) → 规则组合 → 趋势预测
- 简洁/深度双模式：仪表盘卡片 或 ECharts 趋势图（含理想范围色带、滴定/换水标记、滚轮缩放）
- **综合趋势**：多元素归一化为相对变化(%)，对比不同尺度元素走势
- **规则建议带具体行动**：核心元素偏低时给出保守目标，并可跳转元素补充页试算用量
- **元素联动提示**：基于多项记录提供可能原因和复核方向，不把相关性直接表述为确定因果

### 🧪 元素补充计算
- 4 组 10 项试算表（核心/进阶/微量/营养盐补充）
- 不提供酒精/伏特加碳源、铜药或福马林自动剂量：这些方案不能安全套用通用分子量公式
- 输入实测值自动判断缺口并算用量；多添加物可选（如钙可选氯化钙/氢氧化钙）
- 与滴定方案联动：一键把实测值带入滴定页算每天滴定量

### 💧 滴定方案
- 配液浓度计算（分析纯 + RO水）+ 常用配比参考（稀/浓一键填入）
- **消耗测算**：两次实测推算每日消耗
- **目标调节**：输入目标值与计划天数，算出每天滴定量（含每日消耗补偿）
- ⚠️ **每日提升超限提醒**：KH>0.5dKH/天、钙>25ppm/天、镁>50ppm/天 → 红色紧急提示并建议安全天数
- 开始/结束滴定自动记录，趋势图上以色带/标记呈现

### 🧂 换水管理
- 记录换水（水量/盐品牌/备注），趋势图标记换水日
- 海盐品牌用户实测参考（19 品牌；原分享称使用 Hanna 数字比色计，但各列具体型号/方法尚未补齐，未独立复现，不参与自动加药建议）
- 配盐计算：按品牌盐重自动算需要多少克

### 🛡️ 数据与体验
- **数据备份**：JSON 完整导出/导入（自动去重）、CSV 单表导出（Excel 可打开）
- **轻量首次设置**：只问水量、缸型、阶段；详细入门指南改为按需打开，避免连续弹窗
- **PWA 支持**：手机浏览器"添加到主屏幕"即像 App
- **移动端优化**：滑动切 tab、触感反馈、数字键盘、安全区适配、触摸目标 ≥40px
- **"稳字当头"**：全流程贯彻"海缸养的是稳定，切忌大升大降"的养缸理念

## 🚀 快速开始

### 本地运行
```bash
cd seawater-app
pip install fastapi uvicorn
python main.py
# 浏览器打开 http://127.0.0.1:8000
```

### Windows 一键启动（支持手机访问）
```bash
start.bat
# 手机连同一 WiFi，浏览器打开 http://你的IP:8000（start.bat 会提示查 IP）
```

### 手机 PWA 体验
1. 手机与电脑连**同一 WiFi**
2. 浏览器访问 http://电脑IP:8000
3. 浏览器菜单 → **添加到主屏幕** → 像 App 一样使用

## 🗂️ 数据存储

数据保存在本地 SQLite（water_records.db，已 gitignore 不入库）：
- tanks：当前鱼缸档案（实际水量、类型、阶段、自定义目标）
- water_records：水质测试记录
- dosing_log：滴定记录（开始/结束/调整）
- water_change：换水记录

建议定期用「💾 数据备份」导出 JSON 留存。

## 🧠 缸型起始参考（不是必须追逐的统一目标）

应用会根据 FOT / 软体 / LPS / SPS / NPS / 混养选择不同起始范围。实际目标仍应结合盐度、具体生物、营养盐体系、测试方法和长期稳定值设置；不要为了追表格数字频繁大幅调整。

| 参数 | 理想范围 | 备注 |
|---|---|---|
| 水温 | 很多礁岩缸约24-26°C | 以适合本缸生物的稳定温度为主，避免快速波动 |
| 盐度 | 约35ppt | 比重读数受温度与仪器校准影响，以校准盐度计为准 |
| KH 碱度 | 通用参考约7-11 dKH | 结合营养盐、珊瑚类型与长期稳定值设置目标 |
| 钙 | 多数方案起始参考约380-450 ppm | 以本缸类型、盐度与连续消耗为准 |
| 镁 | 通用参考约1250-1400 ppm | 随盐度而变，先核对盐度与复测结果 |
| NO₃ | 按缸型约1-30 ppm | 过低或过高都需结合生物状态与系统负载判断 |
| PO₄ | 按缸型约0.02-0.30 ppm | 长期不可检出可能带来营养限制风险 |
| NO₃与PO₄ | 分别评估 | 不以固定ppm比例作为直接加药目标 |

## ⚠️ 免责声明

本工具仅供鱼友参考，计算结果为估算值（滴定算法源自社区经验公式）。
- 添加前请确认实测浓度，**少量多次、稳字当头**
- 每日提升建议不超过：KH 0.5dKH / 钙 25ppm / 镁 50ppm
- 市售产品请以瓶身/盐袋说明为准；本项目不提供铜药、福马林或碳源的自动治疗/投加剂量
