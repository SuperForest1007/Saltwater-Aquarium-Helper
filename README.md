# 🌊 海水缸助手 ReefPal

一个基于 **FastAPI + 纯前端** 的海水缸管理应用，帮助你管理水质、计算添加剂用量、配置滴定方案。

## ✨ 功能

- 📈 **水质记录与智能分析**：记录测试值，L1-L5分层分析（单点判断/趋势/异常检测/组合诊断/趋势预测），简洁与深度双模式可视化，多元素归一化综合趋势图
- 🧪 **元素补充计算**：KH / 钙 / 镁等元素添加量计算，输入实测值自动判断缺口
- 💧 **滴定方案**：配液浓度计算、每天滴定量估算、浓/稀溶液参考
- 🧂 **海盐参考**：19种常见海盐品牌元素配比与配盐用量计算（比重1.025）
- 📐 **缸体水量估算**：按缸体尺寸估算实际水体
- 🔗 **数据联动**：缸体水量、配比、配液用量全局同步

## 🚀 快速开始

```bash
cd seawater-app
pip install fastapi uvicorn
python main.py
# 浏览器打开 http://127.0.0.1:8000
```

## 📁 项目结构

```
seawater-app/
├── main.py                  # FastAPI 后端入口
├── additive_calculator.py   # 元素添加计算引擎
├── dosing_calculator.py     # 滴定计算引擎
├── water_quality.py         # 水质智能分析引擎（L1-L5）
├── water_store.py           # 水质记录存储（SQLite）
├── static/
│   ├── index.html           # 前端页面
│   └── echarts.min.js       # 图表库（本地化）
└── requirements.txt
```
